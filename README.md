# Sfaizh API

A lightweight Node.js RESTful API designed for blog management, with user authentication, post handling, and Swagger-based documentation. Dockerized for easy deployment.

## Features

- JWT-based authentication
- Blog CRUD operations
- User management
- JSON-based data storage for posts
- Docker and Docker Compose setup

## Getting Started

### Prerequisites

- Node.js (v14 or newer)
- Docker & Docker Compose (for containerized setup)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sfaizh/sfaizh-api
   cd sfaizh-api-main
   npm install
   npm run start
